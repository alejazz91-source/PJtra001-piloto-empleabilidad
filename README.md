# Ruta Empleo Joven

## Propósito
Planificar, organizar y monitorear la ejecución simulada del proyecto Ruta Empleo Joven SG, mediante el seguimiento de actividades, responsables, avances, incidencias y evidencias en GitHub Projects.

## Alcance
El proyecto comprende la planificación, ejecución simulada y seguimiento de 11 actividades operativas de una ruta piloto de empleabilidad juvenil en San Gabriel, con una duración proyectada de 24 meses. Incluye articulación institucional, convocatoria, caracterización, orientación laboral, formación, intermediación laboral y evaluación de resultados, mediante la asignación de responsables, fechas, prioridades, evidencias y monitoreo de avances en GitHub Projects.
